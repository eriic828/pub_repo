# 爆款优化评分引擎 V1.0 - 详细评分标准

## 核心理念

从"技术评估"转向"传播潜力评估"，更符合公众号10w+爆文规律。

## 评分维度（满分120分）

### A. 人设匹配度 (0-100分，权重40%)

#### 1. 关键词匹配 (50分)

**【重要】根据运行模式区分处理：**

**快速查找模式**（用户输入了{UserKeyword}）：
- {UserKeyword}精确匹配（标题或摘要中出现完整关键词）= +25分
- {UserKeyword}语义相关（出现同义词、上位词、相关词）= +15分
- "赚钱"/"变现"/"收入" = +15分
- "AI" = +10分
- "工具"/"应用" = +10分
- 最高50分

> 💡 快速查找模式下，{UserKeyword}是用户最关心的内容，匹配优先级最高

**每日推送模式**（基于热搜词发现动态匹配）：
- 热搜词精确匹配（第一步发现的热点词）= +25分
- 热搜词语义相关 = +15分
- "赚钱"/"变现"/"收入" = +15分
- "AI" = +10分
- "工具"/"应用" = +10分
- 最高50分

> 💡 每日推送模式会先发现热搜词，然后基于热搜词进行动态评分

#### 2. 受众精准度 (50分)

- 主要受众为"技术创业者/程序员/产品经理" = 50分
- 次要受众（泛技术人群）= 30分
- 一般受众 = 10分

### B. 爆款潜力 (0-100分，权重60%)

#### B1. 内容吸引力 (40分)

**数据震撼力 (15分)**：具体、夸张的数据
- 有强震撼数据（如"8个月1亿美金"）= 15分
- 有一般数据（如"月入5000+"）= 8分
- 无具体数据 = 0分

**故事性/戏剧性 (15分)**：冲突、反转、悬念
- 有完整故事弧或多个案例 = 15分
- 有案例片段 = 8分
- 纯干货罗列 = 3分

**争议性/话题性 (10分)**：引发讨论的潜力
- 反常识观点/强观点 = 10分
- 有观点但不突出 = 5分
- 中性陈述 = 0分

#### B2. 传播动力 (40分)

**实操价值 (15分)**：读者能立即行动
- 有完整SOP/工具清单/代码 = 15分
- 有方向但无细节 = 8分
- 纯理论 = 0分

**情绪共鸣 (15分)**：焦虑、希望、认同
- 强烈情绪触发（"被淘汰"/"抓住机会"）= 15分
- 中等情绪 = 8分
- 无情绪 = 0分

**社交货币 (10分)**：转发/收藏价值
- 高谈资+高实用 = 10分
- 仅实用或仅谈资 = 5分
- 无转发动力 = 0分

#### B3. 可读性 (20分)

**标题吸引力 (10分)**：点击欲望
- 符合爆款标题公式 = 10分
- 一般标题 = 5分
- 平庸标题 = 2分

**内容门槛 (10分)**：非技术人也能懂
- 小白友好 = 10分
- 需要一定技术背景 = 5分
- 专家级门槛 = 2分

### C. 时效性加分 (±20分)

**精细化时间段**：
- 近7天内容: +20分
- 近14天内容: +15分
- 近30天内容: +10分
- 31-60天内容: +5分
- 61-90天内容: +2分
- 更早内容: 0分

## 综合评分计算

```
综合评分 = 人设匹配度 × 0.4 + 爆款潜力 × 0.6 + 时效性加分

满分 = 100 × 0.4 + 100 × 0.6 + 20 = 120分
```

## 星级标准

- ⭐⭐⭐ (100分以上): 强烈推荐，爆款潜力极高
- ⭐⭐ (85-99分): 值得创作，传播力强
- ⭐ (70-84分): 备选，有一定价值

## 评分示例

### 示例 1：高分选题（115分）

**标题**：程序员用AI工具8个月赚了1亿美金，他的SOP完整公开

**评分明细**：
- 人设匹配度：95/100
  - 关键词：AI(+15) + 赚钱(+15) + 工具(+10) + 实战(+10) = 50/50
  - 受众：技术创业者 = 45/50
- 爆款潜力：100/100
  - 数据震撼力：15/15（"1亿美金"）
  - 故事性：15/15（完整案例）
  - 争议性：10/10（数据夸张引发讨论）
  - 实操价值：15/15（SOP完整公开）
  - 情绪共鸣：15/15（"抓住机会"焦虑）
  - 社交货币：10/10（高谈资+高实用）
  - 标题吸引力：10/10（符合利益前置公式）
  - 内容门槛：10/10（非技术人也能懂）
- 时效性：+20（近30天）

**综合评分**：95 × 0.4 + 100 × 0.6 + 20 = 118分 ⭐⭐⭐
