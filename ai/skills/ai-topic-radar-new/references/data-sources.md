## 🔴 核心原则：串行搜索 + GitHub API 优先

### 为什么只用 GitHub API AI 热门？

```
✅ 精准：明确搜索 AI/LLM/Agent 相关项目
✅ 高质量：按 Star 数排序，代表真实热度
✅ 高效：一次请求获取30个热点词
✅ 相关性：避免 GitHub Trending 全平台混入非AI项目
```

### curl 热点词获取

```bash
# GitHub API - AI热门项目（唯一来源，最精准）
curl -s "https://api.github.com/search/repositories?q=ai+OR+llm+OR+agent&sort=stars&order=desc&per_page=30" | python -c "
import sys, json
data = json.loads(sys.stdin.read())
for item in data.get('items', [])[:30]:
    print(item['full_name'].split('/')[-1])
"
```

## 搜索策略详解

### 串行搜索流程

```
第1轮搜索
    ↓
等待结果返回
    ↓
检查结果有效性
    ↓
统计累计结果数
    ↓
决策：继续搜索 or 提前终止？
    ↓
第2轮搜索（如需要）
    ↓
... 重复 ...
```

### 提前终止条件

| 累计结果 | 决策 |
|----------|------|
| 累计 ≥ 50条 | 终止搜索，进入评分 |
| 累计 30-49条 | 警告⚠️，继续输出 |
| 10轮后 < 30条 | 搜索结果有限，提示用户 |

### 中文搜索优化

**核心策略**：每轮搜索包含中文关键词组合，提高公众号内容命中率

| 搜索类型 | 中文关键词组合 |
|----------|---------------|
| 教程类 | 教程、保姆级、手把手、零基础、入门 |
| 赚钱类 | 赚钱、变现、月入、副业、收入 |
| 测评类 | 测评、评测、对比、推荐、哪个好 |
| 实操类 | 案例、经验、实操、踩坑、避坑 |

## 搜索技巧

1. **curl优先**：热点词获取用 curl，不消耗搜索额度
2. **串行执行**：一次只发起一个搜索，避免触发限制
3. **提前终止**：结果充足时立即停止，节省额度
4. **多工具补充**：websearch 限制时用 GitHub 搜索补充
5. **关键词组合**：每轮搜索使用多个关键词提高命中率
6. **公众号优先**：搜索时优先包含公众号文章
